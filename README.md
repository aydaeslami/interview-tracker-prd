
# Interview Tracker

A simple web app that helps job seekers organize and track their job applications, interview stages, notes, and follow-ups in one place.

## Project Problem

Job seekers often apply to many roles across different companies at the same time. Important details like application status, interview dates, follow-ups, contacts, and notes can easily get lost across emails, spreadsheets, calendars, and personal notes.

Interview Tracker solves this by giving users one clear place to manage their job search progress.

## User Needs

- Track job applications in one organized place
- Know the current status of each application
- Save interview dates and important notes
- Remember when to follow up
- View progress during the job search process
- Reduce confusion caused by scattered information

## Core Features

- Add, edit, and delete job applications
- Store company name, job title, job link, location, and salary range
- Track application status, such as Applied, Interview, Offer, or Rejected
- Add interview dates and notes
- Add follow-up dates
- Search and filter applications by status
- View a simple dashboard summary

## Requirements

### Functional Requirements

- Users can create a new job application
- Users can update application details
- Users can delete an application
- Users can assign a status to each application
- Users can add notes to each application
- Users can add interview and follow-up dates
- Users can search or filter applications

### Non-Functional Requirements

- The app should be simple and easy to use
- The interface should be clean and organized
- The app should work well on desktop and mobile
- Data should be stored safely
- The app should load quickly

## Possible Tech Stack

- Frontend: React or Next.js
- Styling: Tailwind CSS
- Backend: Node.js, Express, or Next.js API routes
- Database: PostgreSQL, SQLite, or Supabase
- Deployment: Vercel

## Future Improvements

- User authentication
- Email or calendar reminders
- Kanban board view
- Resume and cover letter uploads
- Interview preparation notes
- Analytics for job search progress
- Follow-up email templates

## Project Goal

The goal of Interview Tracker is to help job seekers stay organized, reduce stress, and manage their job search more effectively.
